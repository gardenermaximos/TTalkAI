# TTalkAI
An interactive AI assistant designed to elevate English communication for corporate and executive environments. The application evaluates written text, speech, and vocabulary in real time, offering formal alternatives and executive-level phrasing.

## Core Objectives
- Writing Analysis: Detect informal patterns and convert casual text into formal business prose.
- Speech Recognition: Assess pronunciation, spoken fluency, and formal word choice.
- Progressive Feedback: Deliver contextual corrections and performance metrics during practice sessions.

## Tech Stack
- Python
- Gemini API
- Speech Recognition (STT/TTS)
- VS Code and Git
